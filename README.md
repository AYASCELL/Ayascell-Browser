# 🦅 Ayascell Browser

**Ayascell Browser**, modern web teknolojileri (Electron, React, Vite) kullanılarak geliştirilmiş; hızlı, güvenli ve estetik odaklı yeni nesil bir web tarayıcısıdır. **Ayascell Software** tarafından tasarlanmıştır.

## 🌟 Özellikler / Features

*   **Modern & Premium Tasarım:** Göz yormayan koyu mod (Dark Mode) ve zarif altın (#D4AF37) detaylar.
*   **Tamamen Özelleştirilmiş Arayüz:** Standart işletim sistemi çerçeveleri yerine özel başlık çubuğu ve pencere kontrolleri.
*   **Sekme Yönetimi:** Kolayca yeni sekme açma, kapatma ve sekmeler arası hızlı geçiş.
*   **Güçlü Altyapı:** Chromium tabanlı (Electron) olduğu için tüm modern web siteleriyle %100 uyumludur.
*   **Akıllı Adres Çubuğu:** URL girildiğinde siteye gider, metin girildiğinde otomatik Google araması yapar.

## 💻 Desteklenen Platformlar / Supported Platforms

Uygulama **Cross-Platform** (Çoklu Platform) desteğine sahiptir:

*   **Windows:** Windows 10 ve 11 (x64) - `.exe`
*   **Linux:** Ubuntu, Debian, Fedora vb. - `.AppImage`, `.snap`
